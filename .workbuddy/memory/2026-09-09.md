## Git 环境关键踩坑（本次修复）
- **refs/heads 子目录引用落盘失败**：本沙箱 git 无法在 `.git/refs/heads/` 下创建子目录（feature/req-align、zzz/sub 均 rc=0 但不落盘，扁平引用 _writetest 正常）。修复：直接 Write `.git/packed-refs` 扁平格式 `<full-hash> refs/heads/feature/req-align`，再用 `git -c core.logallrefupdates=false reset --mixed <hash>` 恢复。提交后用同样方式把 packed-refs 指向新提交哈希。
- **post-commit 钩子内联 PAT 修复**：原钩子 `git push origin` 在真实环境无凭证会失败。改为读取 `~/.ghj_publish_token` 拼内联 PAT URL 推送（与 MEMORY 推送姿势一致），main 跳过、fire-and-forget 不阻塞提交。
- **https 推送姿势（沙箱内可用）**：`export PATH=".../mingw64/bin:.../cmd:$PATH"` 后，用内联 PAT URL `https://hzhou1734-pixel:${TOKEN}@github.com/hzhou1734-pixel/153001-ptdpc-ue.git` + `GIT_TERMINAL_PROMPT=0 git -c credential.helper= push <url> <branch>`。feature/req-align 已借此成功推为 new branch（含 v1.0.12+v1.0.13 全量历史）。
- 沙箱内 Bash 默认 coreutils（head/cat/ls/wc/grep）缺失 + 包装器 `cd: null directory`/`dirname: command not found` 警告，命令过滤用 Grep 工具、输出重定向到 `C:/Users/zhou/AppData/Local/Temp/*.log` 再 Read。
